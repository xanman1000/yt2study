# Frontend

React Native app built with Expo SDK 50.

## Setup
```bash
npm install -g expo-cli
npm install
expo start
```

Environment variables (in `app.config.js` or `.env`):
- `EXPO_PUBLIC_YOUTUBE_KEY` – YouTube Data API v3 key
- `EXPO_PUBLIC_BACKEND_URL` – URL of the FastAPI backend
- `EXPO_PUBLIC_SUPABASE_URL` / `EXPO_PUBLIC_SUPABASE_KEY` – Supabase project
